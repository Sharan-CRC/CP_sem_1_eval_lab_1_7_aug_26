# Problem Statement

Write a C program to take the following input of **2 students**:
* **Name**
* **Roll No**
* **Marks obtained** in 3 subjects and 2 lab courses.

---

### Maximum Marks Details
* **Theory Subject:** 50 marks each (3 subjects)
* **Lab Course:** 25 marks each (2 lab courses)
* **Total Maximum Marks per Student:** 200 marks (3 × 50 + 2 × 25)

---

### Requirements & Output Format

1. Display the **Roll No**, **Name**, and **Total Percentage Score** secured by individual students:

| Roll no | Name | Total Percentage |
| :--- | :--- | :--- |
| :--- | :--- | :--- |

2. Display the **Subject-wise Average** for the 3 theory subjects:

| Subject | Student 1 mark | Student 2 mark | Average |
| :--- | :--- | :--- | :--- |
| :--- | :--- | :--- | :--- |
| :--- | :--- | :--- | :--- |
