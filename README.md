# Problem Statement

Write a C program to take the following input of 2 students namely name, Roll no, marks
obtained in 3 subjects and 2 lab courses. The maximum marks for each subject is 50
and lab is 25. Display the roll no, name, total percentage score secured by individual
student and subject wise average for 3 subjects in the following format

### Requirements & Output Format

1. Display the **Roll No**, **Name**, and **Total Percentage Score** secured by individual students:

| Roll no | Name | Total Percentage |
| :--- | :--- | :--- |
| :--- | :--- | :--- |
| :--- | :--- | :--- |

2. Display the **Subject-wise Average** for the 3 theory subjects:

| Subject | Student 1 mark | Student 2 mark | Average |
| :--- | :--- | :--- | :--- |
| :--- | :--- | :--- | :--- |
| :--- | :--- | :--- | :--- |
